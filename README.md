# Pro(doc)ts

Pro(doc)ts is a product-aware documentation engine that bridges the gap between different customer experience levels and variability of product use. Some customers use only one product. Others use three or four together. Some customers are experts who reference docs as a refresher. Others need information from the product story being told to step-by-step directions. 

Consider a company that sells:

* Instrument A
* Instrument B
* Analysis Software
* Data Management Software
* Cloud Platform

Traditional documentation often creates problems here:

* Users encounter instructions for products they don't own.
* Instructions assume integrations or configurations that might not exist.
* Documentation gets duplicated across product-specific manuals.
* Shared workflows are difficult to maintain.
* Users struggle to identify which documentation applies to their particular environment.
